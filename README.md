# Scoop bucket

Scoop manifests for Soham109's open source Windows apps.

```powershell
scoop bucket add soham109 https://github.com/Soham109/scoop-bucket
scoop install soham109/glasspad
```

Manifests are generated from each release's checksums. Source: [Glasspad](https://github.com/Soham109/glasspad).
